How Social Listening Works

Real-time synchronized streams backed by official YouTube embeds and Supabase Realtime.

01

Create or Join a Room

Set up a public space for community discovery or generate an invite code for a private 2–10 person listening session.

02

Synchronized Playback

When the host plays, pauses, or seeks, Supabase broadcasts state updates with automatic drift correction for every listener.

Queue upcoming YouTube tracks together in real time, see who added what, and watch the stream auto-advance.
